# AI Signal Research and Build Plan

This repository stores the design and implementation guidance for a paper-only stock scanning, alert, backtesting, and AI signal-ranking platform.

## Saved documents

- `TradeIdeas-StyleTradingTools_TechnicalResourceMap.md` — sourced technical resource map for scanning, alerts, OddsMaker-style backtesting, paper execution, and integrations.
- `TradeIdeas-Scanner-Alerts-Build-Prompt.md` — autonomous build prompt for constructing the paper-only scanner and alert application.
- `SIGNALFORGE-AI-PLAN.md` — approved plan for the second system, SignalForge AI, which ranks and explains candidate signals generated by the deterministic scanner.

## Project status

The existing scanner and alert application was tested locally in fixture/synthetic mode. Its health endpoint reported `paper_only: true` and `trading_mode: paper`. Real market-data connectivity, Windows PowerShell execution, PostgreSQL deployment, and provider integration require separate verification.

SignalForge AI is currently a plan only. No implementation has been started in this repository.

## Safety

All designs in this repository are for research, backtesting, paper simulation, and hypothetical signal generation. They do not authorize or perform live financial transactions. Do not add live brokerage credentials, live order endpoints, or order-submission code to this repository.
